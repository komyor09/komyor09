## About Me

Junior/aspiring **Python Backend Developer** from Tajikistan, currently working full-stack (PHP/Laravel and Angular/TypeScript) while moving toward a backend-focused, Python-first path (Django, DRF, FastAPI).

I like understanding a system end-to-end — database design, backend logic, and the UI on top — rather than only writing isolated functions. I care about **Clean Architecture**, **Clean Code**, and secure, maintainable design (OWASP/NIST-aware, SSDLC mindset), even on small projects.

### What Drives Me

I enjoy taking a real, messy problem — legacy code, a manual admin process, a business workflow — and turning it into something structured: a proper data model, clear service boundaries, and an interface people actually want to use. I've worked across desktop apps, web backends, Telegram bots, and even network infrastructure, and I'm narrowing that breadth toward deep backend engineering.
